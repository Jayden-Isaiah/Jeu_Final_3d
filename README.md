## Description

Nous avons mis en place les bases du projet pour faciliter les prochaines itérations du projet. Nous avons réalisé un personnage capable de se déplacer dans la scène et entrer en collision avec les murs, du décor, le décor sera amélioré plus tard, pour le moment, ils sont simplement un prototype de leurs versions finales. Finalement, l'environnement du jeu est en place. La fonction principale, collecter des batteries et les insérer dans des panneau.

**Version Unity:**  6000.2.2f1

**Bouger:** WASD ou les flèches
**Intéraction:** E
